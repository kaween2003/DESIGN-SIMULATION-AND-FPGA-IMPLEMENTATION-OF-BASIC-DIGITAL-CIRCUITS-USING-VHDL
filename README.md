# Design, Simulation, and FPGA Implementation of Basic Digital Circuits Using VHDL

This repository contains my Lab 1 work for the **Digital Electronic Design** course at **The Open University of Sri Lanka**.

The main purpose of this repository is to organize and document my VHDL lab work, including design codes, simulation results, synthesis outputs, and FPGA implementation screenshots.

## Lab 1: Digital Electronic Design

In this lab, I designed and tested basic digital circuits using VHDL and Xilinx ISE. The designs were simulated and checked before FPGA implementation.

## Contents

* Basic logic gates using VHDL
* 2-to-1 Multiplexer
* D Flip-Flop / T Flip-Flop
* Test bench files
* Simulation waveform screenshots
* Synthesis and implementation screenshots
* FPGA implementation results

## Tools Used

* VHDL
* Xilinx ISE Design Suite 14.7
* ISim Simulator
* Anvyl FPGA Board

## Purpose

This repository is mainly created for academic learning, practice, and documentation of my FPGA and digital design laboratory work.
