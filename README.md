# DESIGN-SIMULATION-AND-FPGA-IMPLEMENTATION-OF-BASIC-DIGITAL-CIRCUITS-USING-VHDL
This repository contains my Lab 1 work for the Digital Electronic Design course at The Open University of Sri Lanka. It includes VHDL codes, simulation results, synthesis outputs, and FPGA implementation screenshots for basic digital circuits such as logic gates, multiplexer, flip-flops, and related designs.
